## 一、功能

| 功能 | 说明 |
|---|---|
| 反编译 APK | 选择任意 APK，自动反编译出 smali 源码工程（前台服务，不被系统杀死） |
| 深度脱壳 | 全文件字节扫描 dex 魔数，提取隐藏在任意文件中的 dex；检测 360/腾讯/爱加密/梆梆等 10+ 种壳；支持 root 内存转储 |
| smali 编辑器 | 内置文件浏览器 + 代码编辑器，可查看/修改/重命名/删除 |
| AI 助手 | 配置任意 OpenAI 兼容接口，让 AI 分析 smali 并给出修改方案，一键应用 |
| 一键编译 | smali→dex→重建 APK→自动 v1+v2 签名，前台服务保证不被系统杀死 |
| 检测更新 | 启动自动检测 + 设置页手动检测，GitHub Atom Feed + 国内镜像回退（无 API 限流） |
| 二次元壁纸 | 在线随机二次元美少女壁纸，**每 6 秒自动切换，不重复**，API 失败自动回退本地 |
| 存储管理 | 工程文件统一存放在 `/storage/emulated/0/lookapks/`，实际写入测试权限（兼容各 Android 版本） |

## 二、存储路径

所有工程文件保存在：
```
/storage/emulated/0/lookapks/
├── projects/          # 反编译工程
│   └── <工程名>/
│       ├── smali/     # smali 源码
│       ├── apk_src/   # 原始资源
│       ├── original.apk
│       ├── info.json
│       ├── keystore.bin
│       ├── unpacked_dex/  # 脱壳提取的 dex
│       └── output/    # 编译产物
└── output/
```

> Android 11+ 需授予"所有文件访问权限"；Android 6-10 需授予存储权限。

## 三、安装

1. 下载 `ETC-APK-工坊-v2.28.apk`
2. 允许安装未知来源应用
3. 安装后打开，同意许可协议
4. 授予存储权限和通知权限
5. Android 11+ 需在设置中允许"所有文件访问权限"

## 四、快速上手

1. 主界面点击「选择 APK 反编译」或「选择 APK 脱壳」
2. 等待前台服务完成（通知栏可见进度，不会被系统杀死）
3. 进入工程浏览 smali 源码，长按文件可编辑或用 AI 分析
4. 修改完成后点击「编译打包 APK」
5. 编译成功后可直接安装、分享或保存到下载

## 五、AI 配置

在「设置」中配置：
- **API 地址**：OpenAI 兼容端点，如 `https://api.openai.com/v1`（国内需代理）或国内中转/本地服务
- **API Key**：你的密钥（本地免密钥服务可留空）
- **模型名**：如 `gpt-4o-mini`、`deepseek-chat`、`qwen-plus`
- **温度**：0~2，默认 0.7
- **最大 tokens**：默认 2048

点击「测试连接」验证配置是否正确。

## 六、脱壳说明

- 本工具提供**静态脱壳**：扫描 APK 中所有 dex 文件（含 assets/lib 中隐藏的 dex），检测常见加固壳特征。
- 对于动态加密的加固壳（运行时才解密真实 dex），需要在 root 设备上进行内存转储，本工具不提供该功能。
- 脱壳后可对提取的 dex 逐个反编译，找到包含真实 Activity 的 dex 进行修改。

## 七、检测更新

- 启动时自动静默检测（有新版本才弹窗）

## 八、常见问题

**Q: 反编译太慢/被系统杀死？**
A: v2.28 已改用前台服务，通知栏显示进度，不会被系统杀死。大 APK 反编译需要几分钟，属正常现象。

**Q: 编译后安装提示签名不一致？**
A: 重打包使用自签证书（CN=ET APK 工坊），无法覆盖安装原厂商签名的应用，需先卸载原应用。

**Q: AI 连不上？**
A: 国内访问 `api.openai.com` 需代理。推荐使用国内兼容中转服务或本地部署的模型。检查 API 地址是否以 `/v1` 结尾。

**Q: 脱壳后还是壳代码？**
A: 动态加密壳需要 root 内存转储，静态脱壳只能提取未加密的 dex。可尝试对提取的多个 dex 逐个反编译找真实代码。

**Q: 支持哪些 Android 版本？**
A: minSdk 21（Android 5.0），targetSdk 33（Android 13）。纯 Java 实现，32 位/64 位设备均兼容。

## 九、技术栈

- 纯 Java 实现，无 Kotlin、无 AndroidX 依赖
- 内嵌 smali/baksmali 3.0.10 反编译引擎
- 自研 APK 签名器（v1+v2，自签证书持久化）
- 自研 ZIP 写入器（4 字节对齐，等价 zipalign）
- OpenAI 兼容 Chat Completions 客户端
- 程序化 UI（无 XML 布局），暗黑风 + 随机二次元背景
