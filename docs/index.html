ETC APK 工坊

手机上直接用的 APK 反编译、脱壳、改代码、重打包工具。C++ 写的脱壳引擎，不用 root 也能扫出藏起来的 dex。

下载 v2.9 GitHub
v2.9   Android 5.0+   32/64位   MIT

能做什么

纯 Java 加 C++ 原生代码，没有 Kotlin，没有 AndroidX

反编译

选一个 APK，自动拆成 smali 工程。前台服务跑，系统杀不掉，通知栏能看到进度。

C++ 脱壳

原生库扫整个 APK 的每一个字节找 dex 魔数，藏在 so、dat、jar 里的都能挖出来。360、腾讯、爱加密这些壳都能识别。

免 root

静态脱壳不用 root。装了 Shizuku 的话可以开临时权限，拿到 shell 级别操作能力。

改代码

自带文件浏览器和编辑器，smali 直接改。长按文件可以丢给 AI 帮你分析怎么改。

AI 助手

填你自己的 OpenAI 兼容接口就行，本地模型也能用。AI 帮你看 smali、给修改建议。

编译打包

改完一键编译，smali 转 dex，重建 APK，自动签 v1+v2 签名。装手机上直接跑。

换壁纸

界面背景是随机二次元图，每分钟换一张，最近 50 张不重样。网不好自动用本地图。

查更新

开软件自动查，设置里也能手动查。走 GitHub Atom Feed 加国内镜像，不会被限流。

怎么用

从装到用的完整流程

安装

  1. 下载 APK，允许未知来源安装
  2. 第一次打开会弹许可协议，看完勾选同意
  3. 给存储权限，Android 11 以上要在设置里开"所有文件访问权限"
  4. 给通知权限，反编译进度靠通知栏显示

工程文件存在 /storage/emulated/0/lookapks/，文件管理器能直接看到。

反编译

  1. 主页点「选择 APK 反编译」
  2. 选好 APK 后前台服务开始跑，通知栏看进度
  3. 跑完自动进工程目录，smali 文件都在里面

脱壳

不用 root

  • 主页点「选择 APK 脱壳」
  • C++ 引擎扫所有文件找 dex，提取到 unpacked_dex 文件夹
  • 生成一份报告，写了检测到什么壳、提了几个 dex

Shizuku 模式

  • 手机装 Shizuku，用 adb 或 root 启动
  • 设置里开 Shizuku，能拿到 shell 权限做更多操作
动态加密的壳（运行时才解密真实 dex）在没 root 的手机上没法完全脱掉，这是安卓系统本身的限制，不是软件 bug。root 手机可以配合内存转储拿到解密后的 dex。

改完编译

  1. 工程里长按 smali 文件，选编辑或者丢给 AI
  2. 改好保存，点「编译打包 APK」
  3. 等前台服务跑完，就能装、能分享、能存到下载

AI 怎么配

项目填什么例子
API 地址OpenAI 兼容的接口地址https://api.openai.com/v1
API Key密钥，本地服务可以空着sk-xxxx
模型名用哪个模型gpt-4o-mini / deepseek-chat
温度0 到 2，默认 0.70.7

点「测试连接」直接试，不用先保存。

文件都在哪

/storage/emulated/0/lookapks/ ├── projects/ │ └── 工程名/ │ ├── smali/ │ ├── apk_src/ │ ├── original.apk │ ├── unpacked_dex/ │ └── output/ └── output/
