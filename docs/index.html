ETC APK 工坊

安卓平台 APK 反编译、深度脱壳、源码修改与一键重打包工具。内置 C++ 原生脱壳引擎，支持免 root 静态脱壳与 Shizuku 临时权限。

下载 APK v2.9 GitHub 仓库
v2.9  |  支持 Android 5.0 ~ 14  |  32位 / 64位  |  MIT License

核心功能

纯 Java + C++ 原生实现，无 Kotlin / AndroidX 依赖

🔧

APK 反编译

选择任意 APK，自动反编译为 smali 源码工程。前台服务执行，不被系统杀死，通知栏实时显示进度。

🔒

C++ 深度脱壳

原生 C++ 引擎全文件字节扫描 dex 魔数，提取隐藏在任意文件中的 dex。检测 360、腾讯、爱加密、梆梆等 10+ 种加固壳。

🔬

免 root 脱壳

静态深度扫描无需 root。可选 Shizuku 临时权限模式，获得 shell 级操作能力，进一步提升脱壳范围。

✏️

smali 编辑器

内置文件浏览器与代码编辑器，支持查看、修改、重命名、删除。长按文件可直接发送给 AI 分析。

🤖

AI 助手

配置任意 OpenAI 兼容接口，让 AI 分析 smali 代码并给出修改方案。支持本地部署模型，无需联网。

📦

一键编译打包

smali 到 dex 到重建 APK，自动 v1+v2 签名。编译后可直接安装、分享或保存。

🍢

随机二次元壁纸

在线 API 获取随机二次元美少女壁纸，每分钟自动切换，最近 50 张不重复。API 失败自动回退本地壁纸。

🔗

检测更新

启动自动检测 + 设置页手动检测。GitHub Atom Feed + 国内镜像回退，无 API 限流问题。

使用手册

从安装到进阶的完整指南

安装与初始配置

  1. 下载 APK 并安装（需允许未知来源）
  2. 首次启动阅读并同意许可协议
  3. 授予存储权限（Android 11+ 需允许"所有文件访问权限"）
  4. 授予通知权限（前台服务进度通知需要）
  5. 工程文件默认保存在 /storage/emulated/0/lookapks/

反编译 APK

  1. 主界面点击「选择 APK 反编译」
  2. 在文件选择器中选择目标 APK
  3. 前台服务开始反编译，通知栏显示进度
  4. 完成后自动进入工程目录，可浏览 smali 源码

脱壳

免 root 静态脱壳

  • 主界面点击「选择 APK 脱壳」
  • C++ 引擎扫描 APK 中所有文件的字节流，查找 dex 魔数
  • 提取所有找到的 dex 到 unpacked_dex/ 目录
  • 生成脱壳报告，列出检测到的加固壳和提取的 dex

Shizuku 增强模式

  • 安装 Shizuku 应用并通过 adb 或 root 启动
  • 在设置中开启 Shizuku 模式
  • 获得 shell (uid 2000) 级操作权限，可读取更多系统信息
注意：动态加密的加固壳（运行时才解密真实 dex）在非 root 设备上无法完全脱壳，这是安卓系统安全机制限制。root 设备可结合内存转储获取运行时解密的 dex。

修改与编译

  1. 在工程浏览器中长按 smali 文件，选择「编辑」或「用 AI 分析」
  2. 修改完成后保存
  3. 点击「编译打包 APK」
  4. 前台服务执行 smali→dex→重建→签名
  5. 编译成功后可直接安装、分享或保存到下载目录

点击「测试连接」验证配置是否正确（无需先保存）。

存储路径

/storage/emulated/0/lookapks/ ├── projects/ # 反编译工程 │ └── <工程名>/ │ ├── smali/ # smali 源码 │ ├── apk_src/ # 原始资源 │ ├── original.apk │ ├── info.json │ ├── unpacked_dex/ # 脱壳提取的 dex │ └── output/ # 编译产物 └── output/ # 全局输出
